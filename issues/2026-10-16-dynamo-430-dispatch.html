File Menu

File > Open Opens a File Directly

Enhancements

File > Open now opens a file directly. Before, it showed a submenu first.

The menu item is labeled Open... again.

02
Input Nodes

Input Nodes Keep Your Last Valid Value

Enhancements

If you type an invalid value into a Number, Number Slider, Integer Slider, or DateTime node, the node now shows an error and keeps the last valid value. A typing mistake does not replace a value that worked.

The four node types now handle invalid input in the same way.

4
Input Node Types With the Same Error Behavior
Number · Sliders · DateTime
#17281 — An input node showing an error after an invalid value was typed
What This Means for You
If you teach Dynamo, show this to new users: an error on an input node means the last valid value is still in use. The change is PR #17281.
03
Groups

A Collapsed Group No Longer Takes In New Code Blocks

Bug Fixes

Double-clicking the canvas creates a Code Block node. When you double-clicked a collapsed group, the new Code Block node was added into that group. That no longer happens.

0
Code Block Nodes Added Into Collapsed Groups
Groups · Code Block
#17282 — After the fix: the new Code Block node stays outside the collapsed group
What This Means for You
If you found unexpected Code Block nodes inside groups, this bug is a likely cause. The fix is PR #17282.

Also in This Release

Also in 4.3.0: Assistant Review, One-Step Undo, Security Updates

Features · Enhancements · Bug Fixes · Security Fixes

Autodesk Assistant is the AI assistant included with Dynamo. It gains a review window for its changes to Python Script nodes. The window shows the script before and after the change, and you accept or reject it. All edits from one Assistant prompt now undo together in a single step.

Several fixes help daily work. After you undo a code change in a Python Script node, the next run uses the restored code. Save and Save As are no longer disabled when they should be available. After you publish a new version of a package, Package Manager returns you to Installed Packages. Third-party components are updated to versions with no known security advisories.

Entries in the 4.3.0 Bug Fix List

What This Means for You
Start with PR #17373 for the review window and PR #17327 for the undo API. Dynamo also moves to ASM 233, the Autodesk ShapeManager library for geometry operations (PR #17343). The security updates are PR #17383.
Editorial Verdict · Dynamo 4.3.0
Everyday Editing Gets More Predictable
Dynamo 4.3.0 removes small obstacles in daily work: File > Open opens a file directly, input nodes keep the last valid value, and collapsed groups stay closed to new Code Block nodes. It also adds a review window for Autodesk Assistant edits and updates third-party components for security. The release notes flag no breaking changes.
